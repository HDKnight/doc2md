# doc2md API Implementation Plan

> **For agentic workers:** Implement task-by-task. Steps use checkbox syntax for tracking.

**Goal:** Ship a Go HTTP service that converts PDF/DOCX to Markdown via `POST /convert`, with optional small-OCR path.

**Architecture:** Stdlib HTTP server; convert orchestrator; DOCX OOXML; PDF text via ledongthuc/pdf; OCR behind interface + subprocess stub; Block→GFM renderer.

**Tech Stack:** Go 1.22+, net/http, archive/zip, encoding/xml, github.com/ledongthuc/pdf

## Global Constraints

- Max upload 50MB
- OCR mode: auto|on|off (default auto)
- PDF text threshold: ≥50 chars/page average to skip OCR in auto
- No auth in v1
- Project root: `f:\code\java\workspace\aitest\doc2md`
