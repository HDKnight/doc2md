# 四类文档评测与优化总结

日期：2026-10-16

测试集（党政学习语料，本地 `:8080` 转换）：

| 类型 | 样例 | 优化前 | 优化后 |
| --- | --- | --- | --- |
| 题库 PDF | 配套题库 | 嵌套可用；长题干作 `####` | 保持：`### 题型 → #### 题号`；选项不升标题 |
| 思维导图 PDF | 马原思维导图 | 无 OCR 时 503 | `bbox-image`：前 6 页内嵌图，其余注释；不依赖 OCR |
| 章节笔记 PDF | 期末章节笔记 | `## 74` 页码；131 条超长 `##` | 页码剔除；浅层长序号作正文；长标题 131→20 |
| 习题 DOCX | 马发史习题 | （原测图片大纲为空） | 正常：`## 章 → ### 题` 嵌套 |
| 图片型 DOCX | 考试大纲（纯图） | 空 MD 无说明 | `docx-empty` + HTML 注释提示 |
| 扫描简答 PDF | 思政史简答题 | 无 OCR 时 503 | 同导图：页面图降级，不再硬失败 |

## 本轮改动

1. **PDF 无 OCR 降级**：文字层空/导图页不再强行走 Stub OCR；改为整页 PNG 内嵌（`engine=bbox-image`）。
2. **内嵌上限**：最多 6 页、110 DPI，避免 API 返回数十 MB。
3. **浅层长序号**：顶层（逻辑 level≤1）且正文 >48 字的 `1.`/`（1）` 等保持正文；嵌在题型下的长题干仍可作标题（题库）。
4. **裸数字不进标题**：`74` / 空 body 序号不当标题。
5. **世纪粘连**：`19世纪` 不再被拆成 `19 世纪`。
6. **图片 DOCX**：无 `w:t` 时返回明确注释，而非空白。

## 仍可继续优化（未做）

- 配置 `DOC2MD_OCR_CMD` 后，扫描简答/图片大纲可抽真文字。
- 笔记类缺少「章/一、」时仍偏平（大量短 `## 1.`），可引入字号/间距短标题（需几何已部分具备）。
- CLI 模式把导图写到 `assets/`，API 只返回相对路径，进一步缩小 JSON。
- 图片型 DOCX 可对 `word/media/*.png` 做可选 OCR。
