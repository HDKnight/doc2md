# 通用标题护栏（借鉴 pdf-md）

日期：2026-10-16

将 `F:\code\python\demo\pdf-md` 中的大纲规则迁移为 Go `doc2md` 的通用护栏，面向中文教材/题库/讲义类 PDF、DOCX。

## 流水线

文字层 PDF（Go，无 Python）对齐 pdf-md：

```
PDF
 → pdftotext -bbox-layout → Line{text,bbox,…}
 → 导图页：整页 PNG（base64 嵌入）
 → chrome：目录 / 页眉页脚 / 页码
 → layout：双栏先左后右
 → join：几何断行 + 栏间/跨页接缝
 → 拆粘连标题 + OCR 序号归一
 → 序号分类 + 频次成组 + 标题栈
 → 渲染 Markdown（有章标题时从 ## 起）
```

无 bbox / 扫描件仍可走 OCR 字符串路径。

## 核心规则（与 pdf-md 对齐）

1. **选项** `A.`–`D.` 永不做标题。
2. **同类序号**在当前父标题上下文出现 **≥ 2 次** 才成标题，否则当正文。
3. **同类首次成组**时定层级：栈空为 1，否则为栈顶 + 1；之后同类沿用该层级。
4. **`第X章`** 逻辑层级 0（渲染为 `##`）。
5. **`第X部分`** 作为 `part` 族参与栈（正文里「第一部分为…」长句不算标记）。
6. **短行大标题**（简介/导论/绪论等，或首个序号前 ≤24 字短行）可进栈。
7. **序号嵌套（与 pdf-md 一致）**：同类 ≥2 次进入标题栈；新类挂在当前栈顶之下；选择题 `1.`/`2.` 嵌在 `一、题型` 下成更深一级标题（可含填空括号与考研标注）。选项 `A.`–`D.` 永不进栈。
8. **一次标题**：点号/顿号整数、正文 ≤30 且以 `。`/`：` 结尾，仅一次也可成标题。
9. **超过六级**的标题降为嵌套列表。

- `internal/textnorm/tree.go` — 频次 + 栈
